# ⚡ VOCAB 5000 • Hardcore English Sprint

Современное мобильное веб-приложение (PWA) для интенсивного изучения 5 000 самых частотных слов английского языка за **30 дней**.

---

## 🚀 Ключевые возможности

1. **Жесткий режим изучения (Active Recall Typing):**
   * Никакого угадывания по 4 вариантам!
   * Вы видите перевод на русском и/или таджикском языках и **обязаны напечатать английское слово буква в букву**.
   * Любая опечатка или ошибка **сбрасывает прогресс слова до 0** и возвращает его в очередь на повторение.
   * Слово считается выученным, только если вы набрали его без ошибок требуемое число раз.

2. **Программа на 30 дней (166 слов / день):**
   * Все 4 991 слово разбиты на 30 дней.
   * Каждый день поделен на короткие блоки по 28–30 слов, чтобы можно было заниматься спринтами по 5–10 минут.

3. **Синхронизация с сервером (Cloud Persistence):**
   * Серверный эндпоинт `/api/progress` сохраняет ваш прогресс.
   * Вы получаете уникальный идентификатор (Sync ID), который можно ввести на любом устройстве (телефон, планшет, рабочий компьютер), чтобы продолжать обучение с того же места.
   * При развертывании на Vercel поддерживается **Vercel KV / Upstash Redis** или **Supabase** для постоянного облачного хранения.

4. **Двуязычный перевод (RU + TJ):**
   * Полная поддержка перевода на **русский** и **таджикский** языки.
   * Переключение режима в 1 клик: `🇷🇺 Русский`, `🇹🇯 Тоҷикӣ` или `🌐 Оба языка одновременно`.

5. **Нативная озвучка и звуковые эффекты:**
   * Встроенный синтез речи (Web Speech API) автоматически произносит правильное английское слово.
   * Синтезированные звуковые эффекты успеха и ошибок (Web Audio API) без задержек.

6. **PWA (Установка на смартфон):**
   * Откройте сайт в мобильном Safari или Chrome и нажмите «На экран "Домой"» — приложение будет открываться на весь экран без адресной строки браузера.

## 💻 Локальный запуск

1. Установите зависимости (если еще не установлены):
   ```bash
   npm install
   ```

2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте в браузере:
   [http://localhost:3000](http://localhost:3000)

## 🌐 Как опубликовать на Vercel

### Вариант 1: Через GitHub (Рекомендуется)
1. Создайте репозиторий на [GitHub](https://github.com/).
2. Инициализируйте git и отправьте код:
   ```bash
   git init
   git add .
   git commit -m "Initial commit Vocab 5000"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/vocab-5000.git
   git push -u origin main
   ```
3. Зайдите на [vercel.com](https://vercel.com/), нажмите **Add New Project**, выберите ваш репозиторий и нажмите **Deploy**.

### Вариант 2: Через Vercel CLI
В терминале внутри этой папки выполните:
```bash
npx vercel
```
Следуйте простым подсказкам в консоли.

## ☁️ Подключение облачной базы данных на Vercel (по желанию)
Приложение работает сразу из коробки, но если вы хотите постоянную облачную базу данных:
1. В панели проекта на Vercel перейдите во вкладку **Storage**.
2. Подключите **KV** (Upstash Redis) в 1 клик. Переменные окружения подключатся автоматически!
